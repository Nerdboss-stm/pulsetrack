# PulseTrack — Privacy Policy

**Last updated:** 2026-05-11

PulseTrack is an open-source portfolio project for a Senior Data Engineer
interview at WHOOP. It is **not** a public-facing product. Data flowing
through it is one of:

1. Synthetic test data generated by `data_generators/synthetic/`.
2. The repository author's own WHOOP account data, fetched via the WHOOP
   Developer API with the author's own OAuth consent.
3. Public-domain reference data (Open FDA, HAPI FHIR R4 test server).

## Data collected

When the repository author authorizes the PulseTrack WHOOP application,
PulseTrack reads the following endpoints from the author's WHOOP account:

- `/v1/cycle` — daily strain and average heart rate
- `/v1/recovery` — HRV, resting heart rate, SpO2, skin temperature
- `/v1/sleep` — sleep stages, duration, efficiency, respiratory rate
- `/v1/workout` — workout type, strain, HR zones, calories
- `/v1/user/profile` — first/last name, email, user_id
- `/v1/user/measurement/body` — height, weight, max heart rate

The author's WHOOP data is stored encrypted at rest in an AWS S3 bucket
owned solely by the author, and is **never** shared with any third party.

## Data not collected

PulseTrack does NOT collect data from any user other than the repository
author. The application requests OAuth consent from the author only.

## Retention

Data is retained for the duration of the portfolio project. The S3 bucket
has a 30-day lifecycle policy that auto-deletes ingested records. Iceberg
snapshots older than 7 days are expired via `maintenance/compaction.py`.
